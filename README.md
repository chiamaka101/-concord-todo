
# ✅ Concord Todo App

A beautiful, simple Todo app with Categories, Due Dates, and a clean UI.
Built with HTML, CSS, JavaScript + Node.js + Express.

## ✨ Features

- Add / Edit / Delete todos
- Mark as done
- Categories: Work, Personal, Shopping, Health
- Due dates with overdue highlight
- Search + Filter (All / Active / Completed)

## 📁 Project Structure

- frontend/ -> The pretty UI (index.html)
- backend/ -> Node.js + Express API (server.js)

## 🚀 How to Run 

1. Clone it

bash
git clone https://github.com/chiamaka101/-concord-todo.git
2. Start Backend
cd -concord-todo/backend
npm install
npm start
3. Open Frontend

Open `frontend/index.html` in your browser.

## 🛠️ Tech Used

- Frontend: HTML, CSS, JavaScript
- Backend: Node.js, Express
- Storage: JSON file
